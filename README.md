# Financial Self-Care Game 💰

An interactive educational game designed to teach kids foundational financial literacy concepts through engaging gameplay and storytelling.

## Game Levels

### Level 1: Vocab Voyage 📚
- **Objective:** Match financial terms to their definitions
- **Mechanics:** Click-based card matching game
- **Concepts Taught:** Saving, Allowance
- **File:** `level1.html`

### Level 2: The Sound Cipher 🎧
- **Objective:** Listen to sentences and transcribe what you hear
- **Mechanics:** Audio-based input challenge
- **Concepts Taught:** Budget, Cost/Expense
- **File:** `level2.html`

## Features

- 🎮 Gamified learning experience
- 🎨 Colorful, kid-friendly interface
- 💡 Financial literacy education
- 🎵 Audio elements (placeholder structure)
- ✨ Achievement system with XP rewards

## Getting Started

1. Open `level1.html` or `level2.html` in your web browser
2. Follow the on-screen instructions
3. Complete challenges to unlock stories and earn XP
